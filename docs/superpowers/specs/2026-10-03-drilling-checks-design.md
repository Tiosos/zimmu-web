# Stage 4 board drilling and manual review

Assess shared manufacturing records, including hidden parts, with advisory rectangular finished-board hole-array checks. Preserve original part-local machining axes, independent of grain order, band subtraction and placement. A valid array has a positive safe integer count, finite start/pitch, positive finite diameter/depth. Signed pitch follows the existing kernel; zero pitch is valid only for a single hole. Use first/last centres and radius to check both face axes in constant time, not by expanding holes. Reject arithmetic overflow. Entry must lie on the named local face within 1e-6 mm. Through holes (depth >= board dimension along drilling axis) remain valid. Invalid board dimensions produce an explicit unassessed finding.

These checks only assess the rectangular finished-board envelope. Intersections, edge-band blank geometry, mitres, notches, other cuts, overlapping arrays, machining sequence and tool access remain unassessed. Round stock axial/transverse bores get explicit per-operation unassessed findings. Every manual instruction gets a review finding retaining the full captured instruction/template and stable operation/part/cabinet/source IDs. Do not convert manual operations to solid geometry or machine code; without a machine profile compatibility remains unassessed. No machine-ready status and no export blocking.

Add a separate drilling/manual section in UI and PDF, capped at 200 dialog findings with complete exports. Add readiness/machining.json and hashed manifest counts, built from the same captured records as stock checks. Existing stock checks remain separate. Preserve v27, nesting footprints, CSV and drawing geometry.

Validation covers all six faces and U/V axes against existing kernel ordering, reversed rows, single/through holes, invalid numbers/counts, radius/last-hole bounds, overflow, hidden/placed/grain/banded boards, manual instruction detachment, generated shelf/screw drilling, save/reopen, live updates, UI limits, full PDF and packet capture/hash checks. Self-test before publication and verify CI/Chromium.
