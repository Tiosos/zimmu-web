# Room installation and wall-fitted fillers

Implement the selected 50-task batch in docs/cabinet-room-installation.md. Project room geometry remains authoritative, scene commands own installation and filler history. This avoids combining independent project/scene history stacks. Scene installations and wall-filler links carry a bounded cached wall binding refreshed from the current ProjectStructure in App, including missing-source diagnostics; no room geometry is written by installation commands. Preview/accept always refresh from the current project and compare exact project+scene signatures. Source refresh is non-history derivation like existing wall placement synchronisation. Undo installation removes its scene recipe and restores the original cabinet poses in one scene snapshot; wall edits remain project-history operations.

Run installation: explicit ordered member IDs, one room and shared upright container; straight reference wall; inward side, forward/reverse ordering, start/end/centre placement, offset, inter-cabinet spacing, start/end reserve, rear clearance, base/top datum (optional measured site-level reference), floor and optional ceiling. Compute occupied widths and rear limits from existing carcaseBounds/material slots. Convert wall-world poses to the common container without flattening ancestors. Require explicit anchor detachment at acceptance. Reject conflicts with existing project wall placements and other installation runs. Detached runs freeze current poses. Source width/material edits reflow linked members before normal placement and cabinet generation.

Fillers: select room/cabinet/side wall. Require an upright cabinet and a wall parallel to its local depth, spanning the filler thickness at its front/setback; reject tapered/angled/short wall cases. Width is actual lateral gap minus entered wall clearance, bounded by min/max. Generate one role-free, cabinet-child board with material/grain/edges, stock/custom thickness, cabinet-following/custom height and top/bottom clearances. Recipe retains stable board identity; edits preserve independent cuts/operations/visibility. Prevent overlapping duplicate filler gaps; support edit/detach/delete. Missing walls/membership retain last geometry with diagnostics. Machining and manufacturing outputs continue using real existing board/cut representations.

Use existing room clearance/obstacle/door-window assessment plus actual board bounds for advisory interference, and dimensioned plan/elevation previews. Explicit floor/ceiling checks are supplied by installation inputs because RoomGeometry has no ceiling plane. No irregular scribing, sloped walls, structural certification, physical tape-width compatibility or automatic machining routing. No new dependencies. File format 38 stores optional run/filler metadata; old files remain unchanged.
