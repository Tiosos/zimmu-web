# Door and drawer opening motion

Add a nonmodal workspace launched from File. Select a room/cabinet and individual generated fronts; configure generic door angle/hinge offset or drawer travel and inspect a transient opening preview. Persist only validated settings, never open poses. Front IDs bind settings; missing/detached fronts remain repairable diagnostics, never bind by list index. Preview keys include Scene and ProjectStructure. Acceptance recomputes, rejects stale/no-op settings, and commits once through scene history. Format 39 preserves optional metadata across save/load and legacy migration.

Use existing pull/front targets for paired leaf ownership and existing motionDrawer ownership for boxes. Cabinet-local motion matrices rotate a leaf about its stated side/offset or translate a front and driven drawer box together towards negative cabinet Y. Apply only to viewport meshes/edges via an optional world-matrix override map; suppress geometry-edit interactions during preview. Clearing/closing/stale scene resets these overrides. No geometry pipeline, drawing, export or manufacturing consumer reads open poses.

Report conservative interference against actual boards (including fillers/worktops), other moving assemblies, room walls and obstacles. Check intermediate travel positions and simultaneous normalized opening. Conservative world boxes can over-report. Bounded steps and arc error inflation cover intervals; findings never certify a supplier hinge/runner. Use configurable clearance and handle projection envelope. Show clickable findings, plan arcs/travel and elevation dimensions. Animation updates only transient normalized fractions, with cancel/unmount cleanup.

Scope: ordinary generated hinged leaves, upright cabinet frames and straight drawers. Detached/unsupported fronts, supplier-specific multi-link hinges, articulated doors and independent arbitrary timing are explicitly explained. Tests must use absolute world coordinates, rotated parents, both hinge sides, matching drawer boxes, exports unchanged, validation/acceptance/undo/persistence, stale UI, animation and collision cases. Mutation guards must fail by assertions and restore exact bytes. Browser listeners/HTTP may remain blocked locally; do not claim execution if only discovered.
