# Front grain matching and panel sequencing

Start from verified main d1b9c32 (tree 9e703607). Add a named matched-front workspace for generated, upright, same-facing coplanar door/drawer fronts with common material and thickness. Reuse pullTargets/front roles and canonical cabinetSpaceBox; no role-string parsing or geometry copies. Groups own grain direction and derive layout from current geometry. Groups across compatible cabinets are allowed. Detached, tilted, mitred, overlapping and incompatible members produce diagnostics.

Scene.grainMatches owns bounded versioned recipes. The pipeline derives BoardPart.grainMatch bindings and the corresponding normal grain override after all existing generators. Bindings provide group identity, count, sequence, exact cut rectangles, blank dimensions, pattern origin and diagnostics; downstream manufacturing records, labels and nest jobs consume them through existing projections. Group removal clears bindings but preserves individual grain overrides. Missing/incompatible sources retain repairable recipes, mark all present members unavailable for matched nesting and never silently scatter them independently.

Group coordinates are front-view X right and Y downward, in the reference cabinet plane. A front's board X runs upward and board Y right, so member rotation into the common blank is 270 degrees; no mirroring or face flipping. Exact edge deductions shift and reduce each cut rectangle. Additional cutting gap offsets ordered row/column origins, without resizing panels. It removes intervening grain relative to the installed reveals; schematic previews must show this explicitly. Margins reserve blank perimeter. Pattern origin is blank lower-left or the reference front, with signed offsets; it moves schematic grain, never manufacturing dimensions.

Nest each group as one solid rectangular item, then expand its single placement back to real panel identities and a common blank outline. Rotate only the whole group. Validate complete membership, consistent metadata, rectangular bounds and tool clearance between members; unresolved groups become unplaced/excluded, never independent. Preflight fit before allocating a group mask. Recompute utilisation from actual cut panels rather than reserved margins/gaps. Preserve existing behaviour and exact optional output shape for jobs with no groups. Nesting still uses the existing 1 mm raster reservation; mapping retains exact cut coordinates within the reserved frame.

Use a nonmodal File-menu workspace with room/cabinet filtering, individual/multiple selection, group edit/remove/detach, direction/reference/origin/offset/margin/gap controls, installed and blank schematic views, dimension/stock diagnostics, preview/apply, stale source signatures and one scene undo step. Reject competing membership and no-ops; acceptance recomputes and ignores cached preview geometry. Save format 40 validates both recipes and optional derived bindings; older projects still load. Grain-only edits to grouped fronts are routed to this workspace; unrelated material edits may invalidate a group with explicit diagnostics.

Scope: schematic continuity and panel sequencing, not photographic textures, veneer bookmatching, automatic stock purchasing, CNC toolpaths or supplier certification. Tests cover absolute coordinates/edging, mixed layouts, rotated containers, ownership/source failures, atomic nested placement and rotations, impossible stock/clearance, labels/CSV, persistence/history/stale UI and browser workflows. Use exact-backup mutation checks and record actual CI/local limitations.
