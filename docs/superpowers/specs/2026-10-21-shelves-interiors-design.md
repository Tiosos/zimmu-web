# Shelves & Interiors

A dedicated cabinet tab stages InteriorSpec for multiple leaf openings, without modifying dimensions, section identities, front choices, drawer parameters or catalogue pins. Existing single-opening controls remain. Capture counts, pin rows, setbacks and the supported fixed 32 mm pitch. Copy from an opening, standard defaults, clear shelves/drilling, unstage individual edits and select editable openings. Detached shelf roles lock their owning opening.

The 25 tasks are workspace, resolved opening list, multi-selection, select all, clear selection, current settings, fixed counts, adjustable counts, pin counts, row count, front setback, rear setback, fixed pitch display, bulk stage, copy settings, defaults, remove shelves/drilling, unstage, detached locks, input/drilling validation, actual generated shelf checks, insertion diagnostics, cabinet/machining preview, boards/hardware comparison, guarded one-step apply.

Counts bounded at 32 shelves per type/opening and 1000 pin positions; finite nonnegative setbacks, rows 1/2 and pitch 32 only. Limit staged openings to 100 and requested cabinet adjustable shelves to existing readiness limit 1000. Active pin rows must actually generate on both boundary panels, remain inside panel edges/depth and not coincide/overlap. Missing generated fixed/adjustable shelf boards block application; insertion diagnostics explain failed/angled access, without asserting manufacturing approval.

Pure preview uses openingLayoutErrors with retained drawer settings/overrides then applyPipeline. Validate only changed opening shelf/pin requests so existing unrelated limitations do not prevent correcting a selected opening. After regeneration check requested shelf role IDs and actual pin arrays for each changed opening. No board overrides are cleared. Use frontsSignature for geometry/material/drawer/catalogue staleness. Acceptance re-previews current scene/draft, never trusts proposed scene. Whole scene callback creates one discrete undo step. Mesh updates alone do not expire previews.

UI shows indexed physical openings and editable/locked state, current/staged summaries, individual unstage/copy, counts/row/setback form, explicit stage/preview/apply and reset/cancel. Preview includes actual CabinetProjection, shelf board sizes and generated pin bore totals, hardware quantity deltas and insertion diagnostics. Stale edits retain draft but require reset. Tab/cabinet changes clear context safely. No schema migration, dependencies, external writes or import/export in this batch.

Verification: pure guards and geometry tests, unit UI interactions/staleness/locks, scene undo/redo and no-op tests, browser flow plus existing Fronts/Construction regressions; deliberate assertion mutations with exact source restoration; full required typecheck/lint/unit suite, CAD/catalogue builds and isolated Chromium before local commit.
