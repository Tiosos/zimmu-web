# Pending source-review navigation

- Built from main `006fb12`, retaining the release-review follow-up fixes.
- Pending-only is a dialog view preference, initially off, not a review edit or a persisted/exported field. Whole item rows are filtered so completed details and part actions disappear together with their checkboxes. Complete review coverage remains the authority for counts, autosave and both export formats.
- Navigation follows grouped DOM order rather than raw inventory order: manufacturing, metadata, other source sections, limitations. A focused checkbox or note sets the cursor; navigation skips completed findings and wraps. A comparison-context change clears the cursor.
- Checkbox refs avoid constructing CSS selectors from arbitrary stable IDs or source text. Pending-only completion requests focus after React commits the filtered DOM; the final completion focuses the persistent filter control, avoiding focus loss to the document body.
- Validation: 145 tests across eight review/integration files passed; Chromium's real project workflow passed with pending navigation, disappearance/focus assertions, autosave restore and full report exports while filtered. Typecheck, lint and production build passed (existing bundle-size warning). Removing the visibility filter and the pending navigation guard each caused three assertion failures; both mutations were restored before the final passing regression run. Playwright uses click plus disappearance/focus assertions when completion removes the checkbox, since check() waits to inspect the detached target.
