# Cabinet finishing-panel implementation notes

- User selected finishing panels. Branch starts at the completed Layout commit `1714982`; the prior batch remains unmerged and is retained as an ancestor.
- Ordinary non-driven boards avoid a new persisted recipe/schema. Attached parts inherit cabinet transforms but keep explicit dimensions after creation, matching existing manual-board behavior. No label-based ownership or automated replacement/removal.
- Geometry uses local occupied bounds and orientedPanel so panel thickness axes match the existing manufacturing model. These boards do not alter the placement engine's material-slot envelope.
- Preview signatures include source parts and all component transforms, excluding mesh caches and unrelated hardware/pricing metadata. Acceptance rebuilds the board from an independent draft and appends to the current scene with a unique ID.
- The editor adopts the reconciled source signature after successful Add so the newly created board does not leave a false stale-draft warning. Later geometry changes still require Reset. Added a test that previews again after successful addition to verify this transition.
- Thirty-one deliberate guard mutations produced expected assertion failures for material eligibility, supported choices, finite/positive dimensions, nonnegative offsets, plinth depth, source geometry, output/world placement, snapshot/ID safety, stale/error/missing-board acceptance, rebuilding, UI staleness/rejection/reconciliation and undo labelling. Restored source copies and compared them. The Apply mutation initially failed through a missing callback result; strengthened the UI test to assert exactly one callback invocation before inspecting its result, then confirmed the expected assertion failure.
- Final validation passed cleanly: all 202 unit-test files (3,547 passed, 10 skipped), typecheck, lint, CAD production build and catalogue service build. All six traced Chromium workflows passed: finishing worktop/undo/fixed sizing, custom filler/plinth validation, both construction workflows and both multi-cabinet layout workflows. Heavy jobs ran sequentially; the full unit invocation used local networking so catalogue HTTP tests could bind their test port. Whitespace checks passed and the structure reference was regenerated.
