## Implementation

- Recipes live in Scene so accepting, detaching and deleting are atomic scene history commands. ProjectStructure remains authoritative for room walls, membership and site datums. Only world-space wall endpoints/datum and source diagnostics are cached; App refreshes these without pushing history. Scene undo restores recipe/geometry, then refreshes against the current project. Project wall undo follows the existing independent project history.
- Installation resolves before anchors/part generation. Existing anchors require explicit detachment. Legacy project wall placements are rejected to avoid two placement owners. Cabinet members must share an upright parent frame. Occupied dimensions use the existing canonical carcase bounds.
- Filler boards are cabinet-local, role-free rectangular panels with linked metadata. Regeneration runs after cabinet/finishing generation and before run worktops/services. Wall endpoints must describe a side-parallel segment spanning the filler depth. Existing IDs, compatible machining and cosmetic settings are preserved; duplication/detachment produces ordinary boards. Missing sources retain the last geometry rather than destroying manufacturing information.
- Acceptance always recomputes from current scene/project and never trusts a preview's cached geometry. Full scene/project signatures reject stale previews. No-op, identity collisions, competing ownership, invalid stock, unsupported walls and duplicate linked filler gaps are rejected. Nearby geometry, room openings, obstacles and floor/ceiling bounds produce advisory diagnostics using conservative boxes.
- Save format 38 adds optional run/filler metadata. File-boundary validation checks recipe structure without requiring live references, so broken links can be repaired. Both old and current loaders retain the existing migration path.
- The room plan/elevation uses actual transformed opening endpoints; perpendicular openings stay perpendicular in plan and only reference-wall openings appear in elevation. This fixes an early draft that projected every opening onto the selected wall.
- User guide contains the full 50-task list. Browser workflows were added for installation undo/redo, filler lifecycle, linked wall/project undo, save/reload and invalid inputs. Local listeners remain denied by the environment, so browser execution and the six HTTP listener tests require CI; test discovery alone is not execution.
