# Keyboard Shortcuts

## Non-modifier

| Key | Action | Notes |
|-----|--------|-------|
| `F` | Activate snap/align mode | |
| `C` | Activate cut mode | |
| `Escape` | Cancel snap or cut mode | No-op if neither is active |
| `H` | Toggle visibility of selected part | Suppressed in snap/cut mode |
| `Delete` / `Backspace` | Remove selected part | Suppressed in snap/cut mode |

## With Ctrl / Cmd

| Key | Action |
|-----|--------|
| `Ctrl+Z` | Undo |
| `Ctrl+Shift+Z` | Redo |
| `Ctrl+Y` | Redo (Windows/Safari alias) |
| `Ctrl+S` | Save |
| `Ctrl+Shift+S` | Save As |
| `Ctrl+O` | Open |
| `Ctrl+N` | New |
| `Ctrl+D` | Duplicate selected part |
| `Ctrl+Shift+E` | Open cutting list |
