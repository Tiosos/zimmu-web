# Fit a cabinet run to a target span

Open any cabinet's **Layout** tab and change **Layout workspace** to **Fit cabinet run**. Select sibling cabinets, then use Earlier/Later/Reverse to choose their order. The first cabinet defines the target origin in the shared parent's coordinates.

Enter the target span, start/end reserved space, and equal gaps. Reserved space is an allowance only: no filler boards are generated and no site measurement is recorded. Width allocation subtracts those reserves and gaps from the target. Use **Equal widths** or **Proportional to current widths**. Each flexible cabinet has a minimum and maximum width; the solver redistributes space when a limit is reached. **Keep current width** fixes a cabinet at its current width. At least one width must remain flexible. Impossible limits are reported without relaxing them.

X runs require all selected cabinets to face 0° or 180°; Y runs require 90° or 270°. All must face the same direction and be upright. Positive runs start at the first cabinet's occupied minimum boundary; negative runs start at its maximum boundary. Start reserve moves the first cabinet inward from that boundary. Reversing order chooses a new first cabinet/origin. The occupied near edge across the run is aligned; individual heights and rotations stay in place. Coordinates use the parent frame, including when the parent is itself rotated in the project.

Selected anchors require **Detach selected anchors when fitting**. Existing unselected followers remain linked. **Preview run fit** validates cabinet construction, openings and retained drawer boxes, then shows a plan, width/position comparison and fit equation. Material slots determine occupied placement envelopes, matching the existing layout tools; per-board overrides continue to affect construction validation. Linked finishing and worktop recipes follow their existing regeneration/diagnostic rules. Invalid linked recipes can retain their last valid geometry; this preview does not replace their diagnostics or production assessment.

Overlaps are warnings based on sibling occupied envelopes, including unselected anchored followers. Review them before intentionally applying. This is not a room wall, door swing or site-fit assessment; use the existing room assessment for those. Apply changes all fitted widths and positions in one **Fit cabinet run** undo step. Undo and redo restore the complete scene transaction, including dependent geometry. Successful application starts a fresh fit selection; resetting after an external edit also reloads the current cabinet.

Any edit to inputs/order/selection closes the previous preview. Reset or Cancel discards the draft. External geometry, materials, drawer parameters, catalogue/rule or placement changes require reset before preview/apply; worker mesh updates alone do not. Drafts are discarded when switching workspaces or leaving the tab. Save the project normally after applying.
